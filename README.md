## 📌 Overview

A simple front-end e-commerce website built using HTML, CSS, and JavaScript.  
This project simulates a basic online shopping experience including product browsing, cart management, and user interface interactions.

---

## 🚀 Live Demo

👉 https://dongthunhien.github.io/ecommerce-website/

---

## ✨ Features

- 🛍️ Product listing and detail pages  
- 🛒 Shopping cart (add / remove items)  
- 🔐 Login / Register UI  
- 📱 Responsive design (mobile & desktop)  
- 🎯 Clean and simple UI
